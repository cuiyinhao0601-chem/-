DERIVATION · FROM FIRST PRINCIPLES

公式详解 · 从最基础讲起

光 → 质心 → 转动 → 振动 → 振转 → 多原子 → 单位与近似

01光：波长、频率、波数、能量

最原始的两个关系是波速公式和光子能量公式：

c = λ·ν　　　E = h·ν

其中 λ 是波长、ν 是频率、h 是普朗克常数。化学里习惯用波数 ν̃（单位 cm⁻¹），它就是 1 cm 里包含多少个完整波：

ν̃ = 1λ = νc　　　E = hc·ν̃　　　λ = 1ν̃

代入常数 h = 6.626×10⁻³⁴ J·s、c = 2.998×10⁸ m/s，得 hc = 1.986×10⁻²⁵ J·m。于是 1 cm⁻¹ 对应：能量 hc×100 = 1.986×10⁻²³ J；频率 ν = c×100 = 2.998×10¹⁰ Hz；换算成 1.240×10⁻⁴ eV 或 11.96 J/mol。

1 cm⁻¹ → 1.986×10⁻²³ J ＝ 1.240×10⁻⁴ eV ＝ 11.96 J/mol（ν = 2.998×10¹⁰ Hz）

本页横轴用 ν̃；选中一条谱线后，先算 λ = 10⁷ν̃（nm），再算 E = hcν̃，最后看 λ 落在哪个波段。

02双原子分子：质心与约化质量

把质心取在原点，两原子的坐标满足 mHrH + mClrCl = 0，而键长 r = rCl − rH。两式联立：

rH = −r·mClmH+mCl　　　rCl = +r·mHmH+mCl

这正是本页 HCl 两个原子位置的来源。它们到质心的距离之比等于质量的反比，也就是 H : Cl ≈ 35.5 : 1，所以 H 的位移是 Cl 的 35.5 倍（用精确原子质量约 35.2，本页取 35.5 便于口算）。

两个原子相对运动时，真正起作用的不是单个质量，而是约化质量：

μ = mHmClmH+mCl = 0.980 u = 1.628×10⁻²⁷ kg

03转动：刚性转子与转动常数 B

把双原子分子看成两个质点的刚性转子，转动惯量

I = μ·r²

量子力学给出角动量大小 |L| = ħ√(J(J+1))，J = 0, 1, 2, …；转动能是

Erot = L²2I = ħ²2I·J(J+1) = h²8π²I·J(J+1)

把它除以 hc 换成波数，并定义转动常数

B = h8π²cI　⇒　Erot = hcB·J(J+1)　（即 EB = J(J+1)，单位 cm⁻¹）

用 HCl 的 B = 10.4 cm⁻¹ 反推：I = h8π²cB = 2.69×10⁻⁴⁷ kg·m²，r = √(Iμ) = 1.29 Å，与页面取的 1.274 Å 一致，说明这套公式是自洽的。

吸收光子时角动量守恒（光子带一个 ħ），选择定则 ΔJ = ±1；吸收只能取 +1，于是

ν̃ = B(J+1)(J+2) − BJ(J+1) = 2B(J+1)

相邻两条线的间隔恒为 2B = 20.8 cm⁻¹，第一条在 J = 0→1，即 20.8 cm⁻¹。

04振动：简谐近似与力常数

把化学键近似成弹簧，角频率 ω = √(k/μ)，k 是力常数。量子化后

Evib = (v + ½)ħω，v = 0,1,2,…　⇒　ν̃osc = 12πc·√(kμ)

用 HCl 的 2886 cm⁻¹ 反推：k = μ(2πcν̃)² = 481 N/m，正是典型单键的力常数。经典图像就是画面里的

r(t) = r0 + A·sin(2πνt)

真实振动周期是 1cν̃ = 1.16×10⁻¹⁴ s，页面放慢了约 10¹⁴ 倍，所以标了“慢放示意”。

05振转带：P 支、R 支与缺失的 Q 支

同时考虑振动与转动：

E(v,J) = (v+½)hν + hcB·J(J+1)

吸收一个红外光子：Δv = +1（基频），同时 ΔJ = ±1。

ΔJ = +1：ν̃ = ν̃0 + 2B(J″+1)　（R 支）
ΔJ = −1：ν̃ = ν̃0 − 2B·J″　（P 支）

为什么没有 ΔJ = 0 的 Q 支？双原子分子的跃迁偶极矩沿键轴，光子带走一个角动量单位，转动量子数必须改变 1，所以 Q 支被禁阻——带中心是空的。页面里 P 支从 J″ = 1 起、R 支从 J″ = 0 起，两支关于 ν̃0 对称，间隔都是 2B。

06多原子分子：CO₂ 的正常模式与选律

线形三原子分子有 3N−5 = 4 个振动自由度，其中弯曲是二重简并的，所以只有 3 个不同的频率：ν₁ 对称伸缩 1333、ν₂ 弯曲 667、ν₃ 反对称伸缩 2349 cm⁻¹。每个正常模式是一组按质量加权的集体位移；把质心固定后，原子位移由质量比决定（页面每帧都重新扣质心）。

选律的根源是“振动时某个物理量是否变化”：

红外活性 ⇔ (∂μ∂Q)0 ≠ 0　　　拉曼活性 ⇔ (∂α∂Q)0 ≠ 0

ν₁：两个 C=O 键偶极始终严格抵消，μ ≡ 0，偶极矩不随振动变化 → 红外非活性；但键长变化使极化率 α 变化 → 拉曼活性。

ν₂、ν₃：振动过程中 μ 出现并在半周期后反向 → 红外活性；α 的主要部分不随该模式变化 → 拉曼非活性。弯曲的两个互相垂直的平面频率相同（二重简并），所以只有一个 667 cm⁻¹ 的带位置。

08本页用到的近似

刚性转子（转动与振动不耦合）、两个振动能级的 B 相同；简谐振动；偶极矩用形式电荷点电荷模型，只看方向与相对大小；振幅放大、振动慢放，界面都已标注；CO₂ 只画带位置，不分辨转动细结构，也未处理费米共振。
