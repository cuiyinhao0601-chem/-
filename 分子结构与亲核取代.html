关于 分子结构与亲核取代 · 轨道 / SN2 / SN1 / 运动与光谱

核心：实时电子云密度

默认主场景「电子云密度」忠实保留原《类氢杂化》页的计算引擎：类氢径向函数 Rn,l（关联 Laguerre）+ 实球谐角向合成 ψ(r)，在三维网格上计算 ψ² 并用累积分布抽样得到 |ψ|² 电子云点云（相位双色，20k–120k 点可开关）。右侧联动给出二维符号剖面（XY/XZ/YZ）、径向概率 P(r)=Σcᵢ²r²|R|²、能级 En=−13.606Z²/n² 与 Oh 对称性分解。9 个实轨道系数滑杆自由组合、自动归一化。这是实时计算，不是预制动画。

四个化学场景

轨道与进攻CH₃Br 的四个 sp³ 方向、C–Br σ/σ*、羟基 OH⁻（显式 O+H）孤对电子；可拖 ∠Nu–C–Br。σ* 相位、节面与碳侧背向 Br 叶瓣为定性形状，另可开关按杂化/LCAO 采样的 |ψ|² 点云。
Sₙ2OH⁻ 从 Br 背面进攻 CH₃Br；手性 2-溴丁烷走同一段反应坐标，用 R/S、并排与叠合显示构型反转。电子流弯箭头与两根部分键同步。分子均画成显式原子。
Sₙ1t-BuBr 水解：离解 → 碳正离子 → 水进攻 → 质子化醇 → 去质子化。主能量图两峰一谷；另设手性底物的两个进攻面与 Sₙ1/Sₙ2 并排对照。叔丁基/甲基展开为显式 C/H。
运动与光谱HCl/CO₂ 的平动、转动、振动独立开关；HCl 纯转动、红外振转、P(1)/R(0)、同位素；CO₂ 红外弯曲/反称、拉曼对称伸缩、纯转动零偶极与同位素。

分子画法

所有分子均画成显式原子（甲基=C+3H、乙基=C–C+H、叔丁基、羟基/水=O+H），不用基团球或占位球。记号简写（σ、σ*、sp³、R/S、TS）保留。手性 R/S 由 3D 坐标按 CIP 实时判定。

速率模型

Sₙ2 用 v = k[底物][亲核体]：单独加倍任一浓度得 2×，两者都加倍得 4×。Sₙ1 用离解控制模型 v = k[底物]：底物加倍得 2×，只改亲核体浓度时条形高度不变。两图使用同一 0–4.5 尺度，基准均为 1×。

光谱模型与近似

  • HCl 刚性转子 B ≈ 10.4 cm⁻¹；纯转动 J → J+1，线位 2B(J+1)。红外振转取上下振动态转动常数相同的近似，带中心约 2886 cm⁻¹；P 支 ν₀−2BJ″（J″ 从 1 起），R 支 ν₀+2B(J″+1)（J″ 从 0 起），Q 支缺失。线高统一，仅示意，不表示真实强度。
  • DCl 与 HCl 共用平衡键长与力常数：μ=m₁m₂/(m₁+m₂)，B∝1/μ，ν̃₀∝1/√μ。因此 DCl 转动间距约 0.51×、伸缩带中心约 0.717×。
  • CO₂ 使用简谐模型：对称伸缩约 1333 cm⁻¹（C 不动）、反对称约 2349 cm⁻¹（C 反向运动）、弯曲约 667 cm⁻¹（两个垂直平面同频）。拉曼图把 1333 标为模式参考位置；真实 CO₂ 在该区域有费米共振双线（约 1285 / 1388 cm⁻¹），本页面只在注释中说明。
  • ¹²CO₂/¹³CO₂ 只替换中心碳质量：对称伸缩 C 不动，两参考线重合；反对称伸缩 C 参与，¹³C 参考线约 2283.5 cm⁻¹。同位素图横轴范围固定，切换同位素或选中谱线不改变坐标。
  • CO₂ 纯转动电偶极吸收：μ = 0，谱轴为空，仅作选择规律对照；纯转动拉曼不在本页范围。

构型与立体化学

手性 Sₙ2 反应物/产物的 R/S 由 3D 坐标按 CIP 优先级实时判定，构型反转后相反。Sₙ1 手性分支只展示两个进攻面得到的两种立体结果，不给出产物比例；真实比例需要溶剂、离去基团、离子对与实验数据。并排/叠合仅对齐中心碳与观察角度，不表示能量或布居。
