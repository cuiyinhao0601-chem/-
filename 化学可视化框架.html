关于 化学可视化框架 · HCl 伸缩 / SN2 三阶段

框架职责

页面外壳负责场景切换、左侧参数面板、中间 3D 视窗、右侧联动图；窄屏按“关键控件 → 画布 → 播放/进度 → 联动图 → 全部控件”重排。相机、投影、旋转/滚轮/双指缩放、球棍/部分键/轨道叶瓣/箭头/标签、连续时间与有界进度、曲线/棒状谱/条形图/能级图都在公共层。场景只描述状态、frame(state)和charts(state)。

相机 / 3D由原页的 cameraData()、project()、resizeCanvas()、bind3D() 与动画循环提炼；相机状态与时间/进度/选中项分开保存。图元含原子球、键、部分键、轨道叶瓣、电子云 |ψ|² 点云、平面、箭头、标签。
播放连续时间循环；有界进度 0–1，可播放、暂停、倒放、拖动、上一/下一阶段。暂停后相机、图层与谱线点选仍可用。
图表固定坐标范围；游标、选中高亮、点击/触摸命中区；旋转相机或改播放速度不会改变坐标。
注册ChemVis.registerScene(scene) 会自动出现在场景切换器；公共相机、控件、播放、图表立即复用。

新增场景示例（可直接贴进任意场景脚本）

ChemVis.registerScene({
  id: 'pulse', tab: '接入示例', tag: '03',
  playMode: 'time', autoplay: true, playSpan: 4,
  camera: { az: -1.1, el: .25, zoom: 1 },

  initialState() {
    return { time: 0, amp: .5,
      play: { mode: 'time', playing: true, speed: 1, span: 4 } };
  },

  // 左侧参数面板：描述器自动渲染，自动同步
  controls() {
    return [
      { type: 'section', label: '参数', hint: 'DEMO' },
      { type: 'slider', key: 'amp', label: '振幅',
        min: .1, max: 1, step: .01, fmt: v => v.toFixed(2) },
      { type: 'note', text: '只写场景数据，公共层负责相机、控件与图表。' }
    ];
  },

  // 中间 3D：返回图元数据，框架负责投影与绘制
  frame(st) {
    const y = .6 * st.amp * Math.sin(st.time / (st.play.span || 4) * Math.PI * 2);
    return {
      fit: 2.2,
      hud: { title: 'AB', sub: '示例' },
      atoms: [
        { pos: [-.8, 0, 0], r: .28, color: '#e6f2ff', label: 'A' },
        { pos: [.8, y, 0], r: .40, color: '#6fd6ff', label: 'B' }
      ],
      bonds: [{ a: [-.8, 0, 0], b: [.8, y, 0], color: '#9fb6c9' }],
      labels: [{ pos: [0, 0, 0], text: 'A–B', offset: [0, -26], chip: true }]
    };
  },

  // 右侧联动图：曲线、棒状谱、条形图、能级图
  charts(st) {
    return [{
      id: 'wave', kind: 'profile', title: '位移', height: 140,
      x: { min: 0, max: 4, label: 't / s' },
      y: { min: -1, max: 1 },
      curve: Array.from({ length: 81 }, (_, i) => [i / 20,
        .6 * st.amp * Math.sin(i / 20 / 4 * Math.PI * 2)]),
      cursor: { x: st.time % 4, color: '#ffd76e' }
    }];
  }
});

接入说明

  • 把场景定义放在独立 <script> 中，或放进本文件的场景模块区；只要调用 ChemVis.registerScene，无需改页面骨架。
  • initialState() 返回的字段就是唯一联动态：cam、time、progress、sel、play 各自独立。点图、拖进度或换图层时由明确动作修改状态，再由框架重绘 3D 与图表。
  • 复杂交互在 chartClick(state, chartId, hit, api)、handleDrag(state, id, d, api)、action(state, name, payload, api) 中处理；api.go('sceneId', patch) 可带状态跳转。
  • 本页只依赖浏览器原生 Canvas 2D 与 DOM；无 CDN、字体或图片外链，断网可直接打开。

本页两个最小示例

HCl 伸缩验证连续播放/暂停/复位、球棍、质心固定与键长曲线游标。 SN2 三阶段验证有界进度、能量峰点击、两根部分键与原子身份稳定。完整应用把同一份 core.js + charts.js 与场景模块打包进另一个单文件。

模型近似

能量、部分键、轨道形状与电子流均为定性教学示意；真实分子受电子相关、溶剂、温度与振动平均影响。
